# ROADMAP

- HL7 order/result ingestion.
- Matching by sample key.
- Forwarding to LIS with ACK.

## Phase 2 (next)

- Rule engine versionato + explainability.
- QC/operator/device/lot gating.
- ADT ingest + patient/encounter reconciliation.

## Phase 3
- FHIR APIs (DiagnosticReport, Observation, Provenance, AuditEvent).
- Quarantine/review UI completa.
- Device/LIS simulators packaging.

## Phase 4
- ASTM/POCT1 adapters SDK.
- Multi-site governance, CAPA workflows, advanced analytics.
